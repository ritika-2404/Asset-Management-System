# Asset Management System

Tracks company assets, allocation, maintenance, depreciation, and audit trails.

## Features
- Asset Management
- Employee Allocation
- Maintenance Scheduling
- Depreciation Tracking
- Audit Logs

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Run Oracle schema: `sqlplus username/password @db/schema.sql`
3. Run Flask server: `python app.py`
4. Access API: `http://localhost:5000/assets`
